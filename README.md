# 🌦️ DevOps 3-Tier Weather App

A scalable 3-tier weather application built with modern DevOps practices. Fetches real-time weather data and displays it with a clean UI.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Docker](https://img.shields.io/badge/Docker-Ready-blue?logo=docker)

### 🏗️ Architecture - 3 Tier

1.  **Frontend (Presentation Tier):** React.js - User Interface
2.  **Backend (Logic Tier):** Node.js + Express - API & Business Logic
3.  **Database / API Tier:** OpenWeatherMap API + MongoDB (Optional)
